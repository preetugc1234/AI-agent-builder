========================================
VERCEL FRONTEND DEPLOYMENT - SIMPLE STEPS
========================================

STEP 1: GO TO VERCEL
--------------------
1. Open browser
2. Go to: https://vercel.com
3. Click "Sign Up" (top right)
4. Choose "Continue with GitHub"
5. Login to your GitHub account
6. Allow Vercel access


STEP 2: IMPORT PROJECT
--------------------
1. Click "Add New..." (top right)
2. Click "Project"
3. Find "AI-agent-builder" in the list
4. Click "Import"


STEP 3: CONFIGURE PROJECT
--------------------
1. Framework Preset: Select "Vite"

2. Root Directory:
   - Click "Edit" button
   - Type: frontend
   - Click "Continue"

3. Build Settings (should auto-fill):
   - Build Command: npm run build
   - Output Directory: dist
   - Install Command: npm install


STEP 4: ADD ENVIRONMENT VARIABLES
--------------------
1. Scroll down to "Environment Variables"

2. Add Variable 1:
   - Name: NEXT_PUBLIC_API_URL
   - Value: http://YOUR-BACKEND-URL-HERE
   (Get this from BACKEND_URL.txt file)

3. Add Variable 2:
   - Name: NEXT_PUBLIC_WS_URL
   - Value: ws://YOUR-BACKEND-URL-HERE
   (Same URL but with ws:// instead of http://)

Example:
If backend URL is: production-alb-123456.us-east-1.elb.amazonaws.com

Then:
NEXT_PUBLIC_API_URL = http://production-alb-123456.us-east-1.elb.amazonaws.com
NEXT_PUBLIC_WS_URL = ws://production-alb-123456.us-east-1.elb.amazonaws.com


STEP 5: DEPLOY
--------------------
1. Click "Deploy" button (bottom)
2. Wait 2-3 minutes for build
3. You'll see "Congratulations!" when done
4. Click "Visit" to see your live site!


YOUR APP IS NOW LIVE!
========================================

You'll get a URL like: https://your-app.vercel.app

Share this URL with anyone to access your VibeAgent Forge platform!


TROUBLESHOOTING:
--------------------
If build fails:
- Make sure Root Directory is set to "frontend"
- Make sure environment variables are added correctly

If frontend shows errors:
- Check that backend URL is correct (no trailing slash)
- Make sure backend is running (test with TEST-DEPLOYMENT.bat)


DONE! Your platform is fully deployed on AWS + Vercel!
